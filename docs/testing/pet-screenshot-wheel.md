# 悬浮宠物半轮盘与截图验收

目标：App 外长按宠物，保持同一根手指滑动选择，松手执行；「截图并问 DSH-Go」截图后自动回到 App 的新对话待发送区，用户可以继续输入，不自动发送。

## 自动回归

从仓库根目录按可用工具链运行：

```bash
(cd app && flutter analyze --no-pub)
(cd app && flutter test --no-pub test/system_entry test/web/web_mode_test.dart)
python3 app/tool/guide_sync.py --check
python3 app/tool/l10n_merge.py --check
```

原生单测使用 Android/JDK 工具链运行 `:app:testX64DebugUnitTest`，覆盖 `pet.*` 与截图入口相关测试。几何/状态单测不能代替 Android 窗口、实际触摸流、系统截图与 OEM 后台拉起验证。验证结果应附实际命令和输出，不将桌面或桩编译写成真机通过。

## 真机步骤

使用测试页面，不包含真实账号、支付、密码或聊天隐私；构建并安装对应 ABI 的 APK 后执行。不要在运行当前引擎的手机上未经确认覆盖安装或停止 App。

1. 宠物左、右停靠分别长按，保持按住滑到每一项；高亮、轻微放大和凸起应连续变化，松手只执行当前项一次。
2. 长按后不移动直接松手、滑回中心、滑出外圈、多指打断、系统 `ACTION_CANCEL`、旋转、灭屏与窗口代次失效，均不得执行旧选项；普通单击、拖动吸附、拖到 × 隐藏维持原行为。
3. 验证靠顶/底、小屏、横屏、放大字体；半轮盘不截断操作区，必要时降级可滚动的全标签按钮；列表降级模式允许原地抬手保留菜单，再滚动到末项点击，常规半轮盘仍原地抬手取消；无障碍长按仍可点选。点轮盘外收起不执行；原触摸流不为轮盘抢键盘焦点。
4. 开启/关闭系统动画分别操作；检查展开、切换选中与收拢是否连贯、是否存在叠动画、残留浮窗或主线程卡顿。实际帧率需真机帧统计，不凭代码推断「稳定 60 fps」。
5. Android 11+ 且无障碍已连接，在外部测试页面选择「截图并问 DSH-Go」：图片不包含宠物、轮盘或手机操控浮层；自动返回 App，新对话输入区显示图片且获得输入焦点。
6. 在原对话和新对话分别预写文字与附件后重复第 5 步：旧草稿不丢，新草稿原内容保留；继续输入问题，确认图片仍在，且用户点发送之前没有模型请求或图片上传。检查读入后私有截图临时副本被清理、相册无新增。
7. 只开悬浮窗权限但未开无障碍、Android 10 或更低、截图超时/服务断开、安全窗口分别检查明确提示、宠物恢复、无残留缓存、无自动进入错误页面或发送消息。
8. 连续触发、截图期间切主机/回前台/锁屏，旧操作不得在失效后唤起或重复添加附件；后台启动被 OEM 阻挡时测试通知返回入口。
9. 原有「问一句」「新对话」「停止当前任务」「切换主机」「今天不再显示」「宠物设置」全部回归；停止仍针对轮盘打开时固定的会话，切主机的二级操作可达。
10. App 设置为网页模式时，截图同样进入网页新对话输入区，未自动发送；网页失败反馈与附件预算沿用既有分享入口行为。
